Rime 1.0.0 は macOS 15 以降に対応するメニューバー整理アプリです。

- 表示・隠す・常時隠すの3区画
- クリックで一時表示、Option クリックですべて表示
- メニューバー内、またはノッチを避ける下部パネルへの表示を選択可能
- 自動収納、ログイン時起動、初回ガイド
- macOS 26 以降の設定画面に Liquid Glass を採用
- Apple Silicon / Intel 対応、Developer ID 署名、公証済み

ZIP を展開し、Rime.app を「アプリケーション」フォルダへ移動してください。初回起動時に使い方を表示します。
下部パネルを使う場合のみ、macOS のアクセシビリティ許可が必要です。
